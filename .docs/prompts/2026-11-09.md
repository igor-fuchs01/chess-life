# Prompts — 2026-11-09

## 1. Refactor: chess games replaced by exercise lists

**Prompt:** 

> Crie uma nova branch para uma refatoração: a ideia é trocar a partida de xadrez por listas de exercícios de xadrez. Monte um plano para que eu possa revisar e acrescentar as informações necessárias. O banco de dados será remodelado, assim como a dashboard e o HTML. A página `game` será mantida, junto com a API de perfil.

> Retire o módulo de IA do escopo; a verificação da solução dos exercícios vai ficar no navegador.

> O relacionamento entre listas e exercícios é N:N, e cada tentativa registra somente acerto ou erro. Divida os exercícios em 3 níveis: mate em 1, mate em 2 e mate em 3, com 5 exercícios em cada. Os exercícios ficarão cadastrados no nosso banco. Não é preciso fazer migração, apenas sobrescreva tudo. O projeto passa a ser um resolvedor de exercícios, então apague tudo o que for do jogo entre jogadores.

**What was done:** Created the branch `refactor/chess-exercises`, wrote a plan, revised it with the user's answers and implemented it after approval. The documentation changed first (`01-project.md`, `03-database.md`, `04-api.md`, then `02-site-pessoal.md`); the SQL scripts were rewritten (new tables, 15 exercises with solutions, API user recreated); the games API was removed and `listas`, `exercicios` and `tentativas` (routes, controllers, models) were created; `rules.js` loads positions from FEN and lost the draw and game-end rules; `play.html` shows the lists (`lists.js`), `game.html`/`play.js` became the solver, and the dashboard was rebuilt for attempts. Verified on a temporary MySQL 8.0.46 instance (scripts run twice, every constraint rejected when broken) and every route with curl as `chess_life_user`; the browser test was not done because the Chrome extension was not connected. The root `README.md` still describes games and was left for the user to decide.

**Decisions:**

- The game against an AI left the scope — the user's request.
- Lists and exercises are N:N (`lista_exercicio`), and an attempt stores only right or wrong — the user's choice.
- `tentativa` also stores `fk_lista`, with a composite FK to `lista_exercicio` — an exercise can be in more than one list, so the attempt records which one, and the dashboard groups by list.
- The scripts drop and recreate the database and the MySQL user instead of migrating — the user's request; recreating the user also removes the old grants on `partida` and `lance`.
- The solution goes to the browser and the API checks it again on save — the user's choice, for a simple page.
- The 15 exercises come from famous games (Légal, Ópera, Réti–Tartakower, Sempre-Viva, Imortal) and classic patterns, checked with `rules.js` and a mate-in-N search so each user move is the only one that forces the mate; candidates that failed (Blackburne Shilling, Englund, a mate in 3 from the Ópera) were replaced. Three exercises are played by Black.
- The board shows the user's side at the bottom again, since Black-to-move exercises need it; this replaces the uncommitted change in `play.js` that kept White at the bottom.
- "Abertura irregular" was removed from the opening seed — it only matched games with no known opening and would be an odd favorite opening.
- The `--draw` color token and the draw rules of `rules.js` were removed — nothing uses them without games.
- The local development database was not touched: the tests ran on a temporary MySQL instance, because `01-schema.sql` now drops the database.
