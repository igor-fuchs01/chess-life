- Fixed value lists use `VARCHAR` with `CHECK` instead of `ENUM`, as the current `partida` script already does. The doc notes that MySQL enforces `CHECK` only from 8.0.16, so MySQL 8.0+ is required.
- Foreign keys keep the default `RESTRICT`, since the site deletes neither accounts nor openings. Index `(fk_usuario, data_partida)` serves the dashboard's listing.
