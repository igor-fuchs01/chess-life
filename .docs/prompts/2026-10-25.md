## 3. Libraries needed for express-session

**Prompt:**

## 4. Difference between flex: 1 and flex: 2

**Prompt:**

> qual a diferença entre usar flex 1 e flex 2?

**What was done:** Answered the question without changing code. `flex: 1` and `flex: 2` differ only in `flex-grow` (both are `flex-shrink: 1; flex-basis: 0%`), so the number is a share of the free space relative to the siblings: an item with `flex: 2` beside one with `flex: 1` gets two thirds. Also explained that equal values give equal parts, and that `min-width: auto` can let content override the ratio unless `min-width: 0` is set.

**Decisions:**

- None.

## 16. Animated SVG of the Accelerated Dragon on the home page

**Prompt:**

> Invés de utilizar um código que simula a implementação de um tabuleiro de xadrez eu quero um svg animado da abertura dragão acelerado

**What was done:** Replaced the home page board drawn by `home/home.js` with `site-pessoal/public/assets/dragao-acelerado.svg`, an animated SVG that plays 1.e4 c5 2.Cf3 Cc6 3.d4 cxd4 4.Cxd4 g6 with CSS animations, and loops. `index.html` shows it in an `<img class="board">` with an alt text that lists the moves, and no longer loads `home/home.js`, which was deleted since it only drew the board. `.hero .board` got `min-width: 0`, because an SVG with no size of its own made the flex item take the whole row. **Decisions:**

- The SVG lives in `public/assets/`, with the other images, and its colors are written in the file, since an `<img>` cannot read the page's CSS variables.
