# Prompts — 2026-10-25

## 1. Remove bcrypt and store plain-text passwords

**Prompt:**

> Eu quero que você remova o bcrypt desse projeto, as senhas não terão hash e serão armazenadas diretamente no banco de dados

**What was done:** Removed `bcryptjs` (`npm uninstall`) and its use in `usuarioController.js`: sign-up saves the password as is and login compares it with `user.senha`. `usuarioModel.js` and `01-schema.sql` now use `senha VARCHAR(100)` instead of `senha_hash CHAR(60)`. Updated `01-project.md`, `02-site-pessoal.md`, `03-database.md`, `04-api.md`, `README.md` and `CLAUDE.md`. Existing local databases were not migrated: `03-database.md` section 8 has the `ALTER TABLE` to run.

**Decisions:**

- Plain-text passwords, no hashing — the user's choice; they were told anyone who can read the table sees every password.
- The column is renamed to `senha`, since it no longer holds a hash. Discarded: keeping `senha_hash`, a misleading name.
- `VARCHAR(100)` with a new API check `A senha pode ter no máximo 100 caracteres.`, following the name and e-mail length checks, so a long password gets a `400` instead of a MySQL error (`500`).
- The front-end and the request and reply contracts did not change.
