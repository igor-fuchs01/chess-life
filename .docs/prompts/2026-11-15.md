# Prompts — 2026-11-15

## 1. Check whether nodemon picks the dev environment file

**Model:** Claude Opus 5.5, low effort

**Prompt:**

> Usando nodemon faça o ambiente de desenvolvimento ser sempre utilizado, ou seja, quando for utilizado npm run dev o enviroment file a ser utilizado deve ser .env.dev. Portanto adicione uma config no nodemon.

**What was done:** Explained that the `dev` script in `web-data-viz/package.json` (`nodemon --exec node app.js`) does not set `NODE_ENV`, so `app.js` falls back to `.env`, and that nodemon's `env` option (a `nodemonConfig` block in `package.json`) can set `NODE_ENV=dev` for `npm run dev` only. Pointed out the leftover `console.log(ENVIRONMENT_FILE)` in `app.js`. No files were changed.

**Decisions:**

- Suggested `nodemonConfig.env` over `NODE_ENV=dev nodemon ...` in the script — npm runs scripts through `cmd.exe` on Windows, where that syntax fails, and `cross-env` would add a dependency.
- Did not edit `package.json` or `app.js` — environment configuration is changed only on request.
