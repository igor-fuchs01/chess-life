# Prompts — 2026-11-08

## 1. Keep "Jogar" highlighted on the game page

**Prompt:** 

> Quando o usuário estiver na página `game`, o item "Jogar" da sidebar deve continuar destacado com a cor de página ativa, como acontece na página `play`.

**What was done:** The sidebar's "Jogar" link now keeps the `active` highlight on `play/game.html` as well as on `play/play.html`, through an optional `relatedPath` on the menu link in `site-pessoal/public/shared/layout.js`. Documented in `.docs/02-site-pessoal.md`.

**Decisions:**

- Added an explicit `relatedPath` to the "Jogar" link instead of matching any page in the same folder — folder matching would break the home links, which live at the site root.

## 2. Reference documents change only when strictly necessary

**Prompt:** 

> Deixe explícito na documentação que os documentos de referência, como `01-project.md` e `02-site-pessoal.md`, só devem ser alterados quando for estritamente necessário.

**What was done:** Added the rule to the Conventions in `.docs/README.md` and to the Documentation Rules in `.claude/CLAUDE.md`, and recorded it in `.docs/decisions.md`.

**Decisions:**

- "Strictly necessary" means a requirement, business rule, scope, structure, convention, data model or API contract described in the document changes, or the document has become wrong — gives a concrete test instead of a vague one.
- Small fixes and visual tweaks are recorded only in the prompt log — they leave the reference documents true.
- The rule also goes in `.claude/CLAUDE.md`, because its "Never forget to update the documentation" rule would otherwise push toward updating them on every change.
