## 2. Reference documents change only when strictly necessary

**Prompt:**

> Deixe explicito que na documentação como 01-project 02-site-pessoal só devem mudar quando for estritamente necessário

**What was done:** Added the rule to the Conventions in `.docs/README.md` and to the Documentation Rules in `.claude/CLAUDE.md`, and recorded it in `.docs/decisions.md`.

**Decisions:**

- "Strictly necessary" means a requirement, business rule, scope, structure, convention, data model or API contract described in the document changes, or the document has become wrong — gives a concrete test instead of a vague one.
- Small fixes and visual tweaks are recorded only in the prompt log — they leave the reference documents true.
- The rule also goes in `.claude/CLAUDE.md`, because its "Never forget to update the documentation" rule would otherwise push toward updating them on every change.
